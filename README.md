# keyword-storybook-team-project
공공데이터 분석을 기반으로 아동 맞춤형 디지털 동화 서비스를 기획한 팀 프로젝트

# 키워드로 만나는 동화

아동의 흥미와 이해력 향상을 위한 맞춤형 디지털 동화 서비스 기획 팀 프로젝트입니다.

## 프로젝트 구분

- 팀 프로젝트
- 작업 환경: Jupyter Notebook, Google Colab
- 주요 도구: Python, Pandas, Matplotlib
- 결과물: 데이터 분석 코드, 시각화 자료, 최종 발표 자료

## 담당 역할

저는 다음 업무를 담당했습니다.

- 공공데이터 수집 및 분석 항목 선정
- 연령대별 데이터 추출 및 전처리
- 결측값 및 데이터 형식 정리
- 스마트폰 콘텐츠 이용 현황 시각화
- 디지털 기기 첫 접촉 연령 비율 시각화
- 전자책 독서율 추이 시각화
- 분석 결과 해석
- 프로젝트 발표 자료 제작 및 최종 발표

> 본 저장소에는 팀 프로젝트 전체 결과물이 포함되어 있으며,
> 모든 작업을 개인이 단독으로 수행한 것은 아닙니다.
