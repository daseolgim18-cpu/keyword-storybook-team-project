# 데이터 안내

본 프로젝트에서는 아동·청소년의 디지털 콘텐츠 이용 및 독서 환경을 분석하기 위해 공공데이터를 활용했습니다.

## 사용 데이터

### 1. 온라인 디지털 콘텐츠 주 이용매체
- 분석 목적: 아동·청소년의 스마트폰 기반 디지털 콘텐츠 이용 현황 확인
- 사용 항목: 연령대, 이용매체, 이용 비율
- 전처리 내용:
  - 0세~19세 연령대 데이터 추출
  - 분석에 필요하지 않은 항목 제거
  - 결측값 및 데이터 형식 정리

### 2. 책 형태별 독서율
- 분석 목적: 종이책과 전자책 독서 환경의 변화 확인
- 사용 항목: 조사 연도, 연령대, 전자책 독서율
- 전처리 내용:
  - 아동·청소년 연령대 데이터 추출
  - 연도별 데이터 형식 통일
  - 전자책 독서율 추이 분석

## 제작한 시각화

- 0세~19세 스마트폰 온라인 디지털 콘텐츠 주 이용 통계
- 디지털 기기 첫 접촉 연령 비율
- 전자책 독서율 추이

## 원본 데이터

원본 데이터는 공공데이터 제공기관에서 내려받아 분석에 활용했습니다.  
저장소에는 파일 용량과 재배포 범위를 고려하여 원본 데이터 대신 데이터 출처 및 전처리 내용을 정리했습니다.
